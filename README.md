# Python AI Chapter 07: Context Memory Manager

This project is a small Python application that demonstrates how to manage conversational context for an AI agent using a lightweight rolling memory system.

It keeps:
- the most recent conversation turns in active memory
- an older summary of prior context
- the ability to save and reload session state
- automatic summarization when the memory window grows too large

This repository matches the "Chapter 07" example in the Python AI Agents Made Easy series and uses a local Ollama-backed model for responses.

## Features

- Chat loop with a local LLM via Ollama
- Rolling recent-message buffer
- Summary-based long-term memory
- Save and restore conversation history to a JSON file
- Clear, delete, and inspect memory states from the CLI
- Simple command-driven UI for interacting with the app

## Project files

- `main.py` — application entry point and chat loop
- `memory_manager.py` — conversation memory manager and session persistence
- `ollama_service.py` — local Ollama model wrapper for chat and summarization
- `settings.py` — configuration for model, limits, and storage paths
- `requirements.txt` — Python dependencies

## Requirements

- Python 3.10+
- Ollama installed and running locally
- A model compatible with the configured default in `settings.py`

Default model configuration:

- Model: `qwen3.5:9b`
- Host: `http://localhost:11434`

If needed, pull the model:

```bash
ollama pull qwen3.5:9b
```

## Setup

1. Clone the repository.
2. Create and activate a virtual environment (optional but recommended).
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start Ollama locally.
5. Run the app:

```bash
python main.py
```

## CLI commands

The application supports these commands while chatting:

- `/help` — show available commands
- `/history` — display recent conversation exchanges
- `/summary` — show the stored older-context summary
- `/status` — view memory and token usage statistics
- `/save` — save the current session to JSON
- `/load` — restore a saved session
- `/clear` — clear in-memory conversation data
- `/delete` — delete the saved session JSON file
- `/exit` — exit the app

## Memory behavior

The app intentionally keeps a small recent window and compresses older messages into a summary. This reduces prompt bloat while preserving context that matters for continued interaction.

The summary is generated by the LLM, while older message pairs are stored in a compact list. When the recent buffer exceeds the configured threshold, the oldest pair is summarized and moved into the summary memory.

## Session storage

The app saves conversation state to a JSON file under the local app data folder:

- Windows: `%LOCALAPPDATA%\PythonAIAgentsMadeEasy\Chapter07\conversation.json`
- macOS/Linux: equivalent user-local folder used by `Path.home()`

## Notes

This repository is intended as a learning example for context management in AI chat systems. It demonstrates a practical pattern for:

- limiting prompt size
- preserving useful memory across turns
- summarizing older context instead of keeping every prior exchange
- persisting session state between runs
